## Descripción

Documentación de un ejercicio de aprendizaje para procesar datos de viajes de Nueva York con Azure Functions y almacenarlos en Azure Cosmos DB.

## Arquitectura planteada

Dataset de viajes → Azure Function → documentos JSON en Cosmos DB.

| Componente | Papel previsto |
|---|---|
| Python | Lectura y preparación de los registros |
| Azure Functions | Ejecución de la función de procesamiento |
| Azure Cosmos DB | Almacenamiento de documentos |

## Contenido disponible

Este repositorio contiene únicamente este README. El código de la función, las dependencias y la configuración de ejecución no están incluidos, por lo que no ofrece una implementación reproducible ni un endpoint verificable.
